# Security Policy

Report suspected security issues privately to the repository owner. Do not open a public issue containing credentials, session tokens, private artifact URLs, database connection details, exploit payloads, or personal data.

Include the affected route or component, reproduction steps, impact, and the commit or deployment version. Rotate exposed credentials immediately. The project does not offer a bug-bounty program or guaranteed response SLA.

Supported security work is tracked on the current `main` branch. Historical phase branches are retained for engineering history and are not separately supported.
